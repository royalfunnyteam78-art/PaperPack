# Paper Pack - effects guide

General rule: put the effect on the clip itself (drag from Effects onto the clip).
Every effect animates from the start of the clip and stays until the end, so
**cut the clip to the length you want it on screen**, and use "Start Delay" to make it appear later.
Where a "Point" parameter exists, Filmora may show a drag handle in the preview; if not, use the X/Y fields.

| Effect | What it does | Typical use |
|---|---|---|
| Paper Sway | Photo or video flutters like paper in the wind. Pin top/left/right/bottom. | Archive photos, letters, "hanging" posters |
| Torn Paper Note | Clip on a torn paper sheet with shadow. "Blank paper" mode gives a note you write on with Filmora text. | Source/quote notes, map labels |
| Ink Edge Photo | Photo with brushed ink edges on aged paper (or transparent). | History, old stories, documentary B-roll |
| Circle Bubble | Round photo with border that pops in. Move it with Position. | Faces, places on a map |
| Marker Draw | Hand-drawn underline, highlighter, box or circle that draws itself. | Highlight words, mark places on a screenshot |
| Arrow and Route | Curved arrow, dashed arrow or travel route with start dot and destination pin. | Maps, directions, "go here" |
| Slide In Out | Clip slides in/out from any side with bounce. | Photos and clips flying in |
| Sticker Outline | White cut-out outline, glow, shadow. Needs a clip with transparency. | Cut-out people/objects (do background removal in Filmora first) |
| Polaroid Frame | White photo frame with tape, drops in at an angle. | Travel photos, memories |
| Auto Zoom | Slow zoom and pan over the whole clip. | Still photos, calm B-roll |

## Recipes
**Documentary map scene:** map clip on track 1 -> Torn Paper Note (blank paper) on a coloured clip on track 2,
type the source text with Filmora's Title above it -> Circle Bubble on a photo on track 3 ->
Arrow and Route (style: Travel route) on track 4.

**Highlighting text on a screenshot:** put the screenshot on a track, add Marker Draw.
Style "Underline" colour red, or "Highlighter" colour yellow. Set Point A and Point B at the start and end of the line.

**Travel photo montage:** photo -> Auto Zoom, then stack Polaroid Frame on top tracks with different Start Delay values.

**Cut-out person with sticker look:** Filmora background removal -> Sticker Outline (set Glow Size 4 for a coloured glow).
